# Установка VK Tools

## Установить

1. Закройте Revit (иначе файлы надстройки заняты и установка попросит перезагрузку).
2. Запустите `VKTools-<версия>.msi`. Права администратора не нужны: ставится только для вас.
3. Откройте Revit. При первом запуске Revit спросит про надстройку без цифровой подписи —
   выберите **«Всегда загружать»**.
4. Появится вкладка **VK Tools**.

Ставится сразу для Revit 2021, 2022 и 2024. Если какой-то из них не установлен, его папка просто не используется.

Где взять MSI: GitHub → репозиторий → Actions → последняя успешная сборка `build` → артефакт **VKTools-msi**
(zip с MSI внутри). Позже — страница Releases.

## Обновить

1. Закройте все окна Revit.
2. Запустите MSI новой версии. Удалять старую не нужно и не надо: установщик сам заменяет
   предыдущую версию (у всех версий один код обновления), в «Приложениях» остаётся одна запись **VK Tools**.
3. Откройте Revit → VK Tools → «О программе»: там должна быть новая версия.

Что можно удалить после обновления: скачанные zip и MSI. Что оставить: `%AppData%\VKTools` (настройки)
и `%LocalAppData%\VKTools\logs` (логи, старше 30 дней удаляются сами).

Конфликт версий бывает только если файлы надстройки когда-то копировали вручную. Проверьте, что
`VKTools.addin` и папка `VKTools` есть только в `%AppData%\Autodesk\Revit\Addins\<год>\`; копии в
`C:\ProgramData\Autodesk\Revit\Addins\<год>\` или других местах удалите (Revit тогда грузит
надстройку дважды и пишет об ошибке загрузки).

## Удалить

Параметры Windows → Приложения → **VK Tools** → Удалить. Настройки и логи остаются
(`%AppData%\VKTools`, `%LocalAppData%\VKTools`) — их можно удалить вручную.

## Что куда ставится

```
%AppData%\Autodesk\Revit\Addins\2021\VKTools.addin
%AppData%\Autodesk\Revit\Addins\2021\VKTools\VKTools.dll, VKTools.Core.dll, config\*.csv
… то же для 2022 и 2024
```

## Если что-то не так

| Симптом | Что сделать |
|---|---|
| Нет вкладки VK Tools | Если при запуске Revit нажали «Не загружать» — перезапустите Revit и выберите «Всегда загружать». Иначе проверьте, что есть `%AppData%\Autodesk\Revit\Addins\<год>\VKTools.addin` |
| Revit сообщает об ошибке загрузки VK Tools | Пришлите лог: VK Tools → О программе → Открыть папку логов (`%LocalAppData%\VKTools\logs`) |
| Кнопка «Проверить модель» серая | Открыто семейство или нет открытого проекта |
| Установка просит перезагрузку | Был открыт Revit. Закройте его и запустите MSI ещё раз |
