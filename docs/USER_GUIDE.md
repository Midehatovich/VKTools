# VK Tools — инструкция пользователя

Версия плагина: **0.12.1**. Revit 2021, 2022, 2024.
Для кого: проектировщики отдела ВК, которые выпускают спецификации из модели.

VK Tools заменяет Dynamo-скрипты, которыми мы готовили модель к выпуску: объединение систем, система и этаж,
изоляция, группирование, расчётные позиции, запас труб. Всё делается кнопками на вкладке **VK Tools**.

## 1. Главное за одну минуту

- **Плагин ничего не делает сам.** Только по кнопке. Пока вы не нажали «Применить», модель не меняется.
- **Сначала смотрим, потом пишем.** Каждое окно показывает «было → станет». Перед записью — «Пробный прогон»:
  плагин записывает, проверяет и откатывает обратно.
- **Ctrl+Z отменяет всё сразу.** Одно «Применить» — одна строка в журнале отмены.
- **Настройки хранятся в модели.** Один раз настроили и нажали «Сохранить» — после синхронизации у коллег то же самое.
- **Нет данных — значение не трогается.** Плагин ничего не придумывает: спорный элемент попадает в отчёт, а не в модель.

## 2. Установка и обновление

### Установить

1. Закройте **все** окна Revit.
2. Запустите файл `VKTools-0.12.1.msi`. Где его взять — спросите у Радмира (он выкладывает новые версии).
   Права администратора не нужны.
3. Откройте Revit. Появится вопрос про надстройку без цифровой подписи — нажмите **«Всегда загружать»**.
4. В ленте появится вкладка **VK Tools**.

Плагин ставится сразу для Revit 2021, 2022 и 2024.

### Обновить

Закройте Revit и запустите MSI новой версии. Старую удалять **не нужно**: установщик заменит её сам.
Проверка: VK Tools → **О программе** → номер версии.

### Удалить

Параметры Windows → Приложения → **VK Tools** → Удалить.

Подробнее и про редкие случаи — [INSTALL.md](INSTALL.md).

## 3. Как устроено любое окно

Все кнопки, которые меняют модель, работают одинаково.

```
 ┌─ Вкладка «Настройка» (или «Параметры», «Таблица групп», «Спецификации»…)
 │     что и куда писать; таблицы правил проекта
 ├─ Вкладка «Было → станет»
 │     список изменений: элемент, параметр, было, станет
 └─ Внизу: «Сводка, правила и сообщения Revit» (раскрывается)
       итоги, предупреждения, ошибки

 [По умолчанию] [Сохранить]        [Обновить] [Пробный прогон] [Применить] [Закрыть]
```

| Кнопка | Что делает | Меняет модель? |
|---|---|---|
| **Обновить** | Заново анализирует модель с настройками окна. Нажимайте после любой правки настроек или модели | Нет |
| **Пробный прогон** | Записывает, проверяет и откатывает. Показывает, получится ли запись | Нет |
| **Применить** | Записывает одной операцией. Доступна только после успешного пробного прогона с теми же настройками | **Да** |
| **Сохранить** | Сохраняет настройку окна в модели. Значения элементов не меняются | Только настройку |
| **По умолчанию** | Возвращает в окно настройки отдела. В модель попадут после «Сохранить» | Нет |
| **Показать в модели** | Выделяет элементы выбранных строк (или двойной щелчок по строке) | Нет |
| **Сохранить CSV…** | Отчёт в таблицу для Excel | Нет |

Как читать отчёт:

- **Жирная строка вверху** — итог: «будет изменено N, без изменений M, ошибок, предупреждений».
- **Красная строка «Запись запрещена»** — плагин нашёл то, что может испортить данные. «Применить» не нажмётся,
  пока причина не устранена. Причина написана в этой строке.
- **Предупреждение** — запись возможна, но посмотрите строку глазами.
- **Повторный запуск после «Применить»** должен показать «будет изменено 0». Если нет — значения кто-то переписывает
  (обычно BIM2B или формула в семействе). Сохраните CSV и сообщите.

## 4. Порядок работы перед выпуском

```
 0. Проверить модель        ← что не так с параметрами и данными (только чтение)
 1. Объединить системы      ← «В1 1», «К1 3» → «В1», «К1»  (если копии есть)
 2. Система и этаж          ← система и этаж всем элементам + перенос во вложенные
 3. Изоляция                ← Dнар трубы, наименование, марка, завод
 4. Группирование           ← ADSK_Группирование и комплекты
 5. Расчётные позиции       ← металл, грунтовка/краска, шнур, запас 20 % на хомуты
 6. Запас труб              ← количество труб и изоляции × 1,1
 7. Имена труб              ← пока только проверка
 8. Проверить модель        ← ещё раз, контроль
```

Почему именно так: каждый следующий шаг берёт данные, которые записал предыдущий.
Расчётные позиции считаются по системам и этажам, поэтому система и этаж должны быть уже проставлены.
Запас труб идёт после расчётных позиций, чтобы металл и краска считались по чистой длине.

Шаги можно повторять сколько угодно: если всё уже записано, плагин покажет «изменений 0».

Перед началом — **синхронизируйтесь**. После последнего шага — **синхронизируйте с освобождением элементов**.

## 5. Кнопки по порядку

Вкладка VK Tools состоит из четырёх панелей:

```
 Проверка        Системы                     Спецификация                                               Сервис
 [Проверить   ]  [Объединить] [Разрывы ]     [Система] [Изоляция] [Перенос во] [Группи-] [Расчётные] [Запас] [Имена]   [Настройки] [О программе]
 [модель      ]  [системы   ] [стояков ]     [и этаж ]            [вложенные ] [рование] [позиции  ] [труб ] [труб ]
```

### 5.1. Проверить модель

**Что делает.** Только читает модель и показывает отчёт. Ничего не меняет.

Что проверяется:

- есть ли в проекте нужные параметры ФОП и отмечены ли у них нужные категории;
- работают ли в модели апдейтеры других надстроек (BIM2B и др.), которые могут переписать значения;
- элементы с пустым **ADSK_Наименование**;
- изоляция, у которой этаж или система не совпадают с трубой;
- разные написания одного значения: «В1» кириллицей и «B1» латиницей, «02 этаж» и «02 Этаж», лишние пробелы.

**Как пользоваться.**

1. Нажмите **Проверить модель**.
2. В отчёте отфильтруйте по важности: сначала «Ошибка», потом «Предупреждение».
3. Выберите строку → **Показать в модели**, исправьте.
4. Для изоляции с чужой системой или этажом в строке есть подсказка: это лечится кнопкой «Система и этаж».

### 5.2. Объединить системы

**Зачем.** При копировании этажей Revit создаёт копии систем: «В1 1», «В1 2», «К1.2 3». В спецификации они
разъезжаются по разным строкам. Кнопка переносит копии в основную систему «В1», «К1.2».

**Как пользоваться.**

1. Синхронизируйтесь.
2. Нажмите **Объединить системы**. Откроется список копий с состоянием:
   - **Готова** — можно объединять, отмечена сразу;
   - **Нужна ваша отметка** — плагин не уверен. Нажмите «Показать в модели», убедитесь, что это та же система, и отметьте вручную;
   - **Не объединяется** — причина в колонке «Пояснение» (нет основной системы, копия занята коллегой, в группе и т. п.).
3. **Пробный прогон** → если зелёный → **Применить**.
4. Синхронизируйте с освобождением элементов.

Во время работы показывается окно прогресса с кнопкой «Отменить». На больших системах это может занять минуты.

Если копию объединять не нужно, отметьте её **«Не объединять»**. Эта отметка хранится только на вашем
компьютере (см. [Ограничения](#7-известные-ограничения)).

### 5.3. Разрывы стояков

Только чтение. Ищет куски стояков, которые не соединены друг с другом: свободные концы одной системы на одной вертикали.
Типичная причина — скопировали этаж, а стояк не соединили с нижним, и Revit считает куски разными системами.
В отчёте **Показать в модели** выделяет оба конца разрыва. Соединяйте руками, потом снова «Объединить системы».

### 5.4. Система и этаж

**Что делает.**

- Параметр системы (по умолчанию **LSR_Имя системы**) = «Сокращение для системы».
  Если у фитинга или арматуры сокращения нет, берётся у соседних элементов (до 3 шагов по сети).
- Параметр этажа (по умолчанию **ADSK_Этаж**) = имя уровня элемента. В таблице этажей можно задать своё значение
  вместо имени уровня (например, уровень «Отм. +3.000» → «01 этаж»).
- Изоляция получает систему и этаж своей трубы.
- Затем, если стоит галка, — **перенос во вложенные** в той же операции (см. 5.6).

**Как пользоваться.**

1. Нажмите **Система и этаж**. На вкладке «Настройка» проверьте, в какие параметры писать и какие категории обрабатывать.
2. Если имена уровней не годятся для спецификации, заполните таблицу этажей колонкой «Своё значение».
3. **Сохранить** (настройка запомнится в модели), затем **Обновить**.
4. Посмотрите «Было → станет». Элемент, который подключён к двум системам или ни к одной, не меняется и висит в отчёте — посмотрите его.
5. **Пробный прогон** → **Применить**.

Если проект не ЛСР и параметров LSR_ нет, выберите в окне свои параметры. Плагин к LSR не привязан.

### 5.5. Изоляция

**Что делает.**

- Пишет в изоляцию наружный диаметр трубы-основы (по умолчанию в **U_Наружный диаметр**). У фитингов и арматуры —
  диаметр присоединённой трубы; на переходе берётся больший, а в отчёте пометка «ПРОВЕРИТЬ».
- По таблице **«Изделия»** пишет наименование, марку, завод и любые другие параметры. По умолчанию одна строка:
  ROCKWOOL, «… толщиной 25 мм для трубы D = 57 мм», ADSK_Марка «ТУ 5762-050-45757503-15», завод «ROCKWOOL».

**Как пользоваться.**

1. Нажмите **Изоляция**. На вкладке «Настройка» внизу превью: тип изоляции в модели → какая строка таблицы подошла → пример имени.
   Проверьте, что каждый тип нашёл свою строку.
2. Если в проекте другая изоляция — добавьте строку в таблицу «Изделия» (маска типа, основа имени, марка, завод).
   Нужен ещё параметр — «+ Колонка». Строки проверяются сверху вниз, срабатывает первая подходящая.
3. Наименование пишется, только если стоит галка **«Писать наименование в»**. Важно: тогда в BIM2B нужно убрать формулу
   имени изоляции, иначе BIM2B перепишет имя обратно. Плагин предупреждает, если видит апдейтер BIM2B.
4. **Сохранить** → **Обновить** → **Пробный прогон** → **Применить**.

### 5.6. Перенос во вложенные

**Зачем.** Вложенные общие семейства (хомуты, кран в шкафу) попадают в спецификацию отдельно. Им нужны те же
этаж и система, что у родителя.

**Что делает.** Копирует выбранные параметры родителя во все его общие вложенные семейства.
По умолчанию: ADSK_Этаж, LSR_Имя системы, LSR_Тип системы.

**Как пользоваться.**

1. Обычно отдельно запускать не нужно: это делает «Система и этаж» с галкой «Затем перенести во вложенные».
2. Отдельно — когда поменяли родителя вручную. Выберите область: вся модель, активный вид или выделенные элементы.
3. На вкладке «Параметры» отметьте, что переносить. Тип данных у родителя и вложенного должен совпадать.
   Пустое значение у родителя не переносится.
4. **Обновить** → **Пробный прогон** → **Применить**.

### 5.7. Группирование (и Комплекты)

**Что делает.** Заполняет **ADSK_Группирование** по таблице групп проекта, чтобы спецификация шла в нужном порядке:
0 — спринклеры … 8 — прочее, 9.x — расчётные позиции.

**Вкладка «Таблица групп».**

- Строка по категории или по семейству (маска с `*`, например `*Кран поливочный*`).
- Строка семейства действует и на его вложенные.
- **«Не трогать»** — для элементов, которым группу ставите вручную (например, гильзы PA_Гильза в ПТ).
- Порядок строк важен: среди строк семейств срабатывает первая подходящая.
- «Импорт…» загружает таблицу из файла: так можно взять настройку из другого проекта.

**Вкладка «Комплекты».** Для изделий, которые идут в спецификации комплектом (пожарный шкаф, поливочный кран):
родитель и его вложенные получают группу «группа.номер комплекта.ранг» и стоят в спецификации подряд, как ШПК:

```
 4.000000001.00   Шкаф пожарный ШПК-…     ← родитель, ранг .00
 4.000000001.01     Кран пожарный DN50    ← вложенный, ранг .01
 4.000000001.02     Рукав …               ← вложенный, ранг .02
```

Длинный номер с нулями нужен, чтобы спецификация сортировала комплекты по порядку (10-й после 9-го, а не после 1-го).

1. Найдите семейство в списке, отметьте вложенные, которые входят в комплект. Семейство станет комплектом.
2. Порядок отмеченных (стрелки «выше/ниже») задаёт ранг .01, .02 — порядок строк внутри комплекта.
3. Состав можно задать для всего семейства или отдельно для одного типоразмера.
4. Номер комплекта у типоразмера не меняется между запусками.

Затем **Сохранить** → **Обновить** → **Пробный прогон** → **Применить**.
Служебные позиции `_SYS_…` группирование не трогает.

### 5.8. Расчётные позиции

**Что делает.** Добавляет в спецификацию строки, которых нет в модели как элементов, по каждой системе:

| Позиция | Как считается |
|---|---|
| Грунтовка и краска | площадь труб π·Dнар·L × расход. Оцинкованные трубы не красятся — для них только металл |
| Металл для креплений, кг | число креплений по шагу (СП 73.13330.2016, п. 6.1.8, табл. 2) × масса |
| Бентонитовый шнур | по длине гильз на трубах, как в Excel «Расчет гильз и шнура» |
| Запас на штучные | хомуты Rapid, Kralle, Grip E W2 и муфты грувлок: +20 % по строке спецификации, с округлением вверх |

Позиции — экземпляры служебного семейства `_SYS_SpecCalcItem`. Если его нет в проекте, плагин создаст его сам.
Строка запаса сливается со строкой хомутов: отдельной строки «запас» в спецификации не будет.

**Как пользоваться.**

1. Нажмите **Расчётные позиции**. Вкладка **«Спецификации»**: отметьте «Считать» у тех спецификаций, в которые
   должны попасть позиции (например, 4 спецификации: водопровод/канализация × подземная/надземная часть).
   Позиции считаются отдельно для каждой спецификации и с её фильтрами.
2. Вкладки «Ресурсы», «Правила для труб», «Крепления», «Гильзы и шнур», «Запас на штучные» — таблицы проекта.
   Обычно их не трогают. Свой завод-изготовитель для металла пишется в колонку на вкладке «Ресурсы».
3. **Гильзы и шнур:** укажите семейство гильз (по умолчанию маска `*ильз*`) и «Длина гильзы» — если в семействе нет
   параметра длины, выберите «(по геометрии вдоль трубы)». Если включено «Только гильзы в наружных стенах»,
   **загрузите связи АР/КР**: без наружных стен шнур не посчитается и запись будет запрещена.
4. **Сохранить** → **Обновить** → **Пробный прогон** (проверяет, что позиции попадают в свои спецификации) → **Применить**.

**Ручная поправка количества.** Не правьте «Кол.» в спецификации: при следующем запуске оно перепишется.
Впишите значение в параметр позиции **«SYS_Кол-во вручную»** — он перекрывает расчёт. Очистите — вернётся расчётное.

### 5.9. Запас труб

**Что делает.** Количество (по умолчанию **ADSK_Количество**) = длина × k для жёстких труб и изоляции на трубах.
По умолчанию k = 1,1 (запас 10 %, ТЗ главного специалиста).

Не трогаются: гибкие трубы, изоляция фитингов, элементы с «!» в имени.

**Как пользоваться.**

1. Нажмите **Запас труб**. Раскройте «Сводку» и найдите строку про единицы количества: должно быть
   «число (метры как есть)». Если плагин не понял единицы — запись запрещена, сообщите.
2. Таблица **«Коэффициенты»**: категория, маска типа, системы, k. Пустой k — «не трогать».
   Пример: для системы К1 запас не нужен — строка с системой К1 и пустым k выше общей строки.
3. Внизу вкладки «Настройка» — суммы по системам «было → будет». Сверьте с ожиданием.
4. **Пробный прогон** → **Применить**.

В сводке также видно, кто последним менял количество и какой запас сейчас (×1 или ≈×1,1): так видно трубы,
которые BIM2B или ручная правка сбросили обратно.

### 5.10. Имена труб

**Что делает сейчас.** **Только проверка.** Показывает трубы, чьё ADSK_Наименование не совпадает с правилом бюро:

- ВГП по ГОСТ 3262 и чугун — по условному проходу: «… ø15x2,8»;
- остальные трубы — по наружному диаметру: «… ø110x2,7».

Основа имени — «Комментарии к типоразмеру» трубы. Если они пустые, труба не получит имя и будет в отчёте.

Ещё в отчёте строка **«одна труба — несколько строк спецификации»**: например, ВГП DN15 в двух строках
«ø15x2,8» и «ø21.3x2,8». Это сигнал, что часть труб названа по-другому.

**Как пользоваться.**

1. Нажмите **Имена труб**. В шапке «Было → станет» — «только проверка».
2. Посмотрите расхождения, **Показать в модели**.
3. Галку **«Записывать имена труб в этом проекте»** не включайте, пока имена труб пишет BIM2B: он перепишет их обратно.
   Решение о включении принимает Радмир.

### 5.11. Настройки и О программе

- **Настройки**: папка правил отдела и срок хранения логов. Без необходимости не меняйте.
- **О программе**: версия плагина, кнопки «Открыть папку логов» и папку правил. Версию указывайте в каждом отзыве.

## 6. Работа в общей модели

- **Перед запуском — синхронизация.** Иначе плагин не сможет изменить элементы, занятые коллегами:
  они попадут в отчёт строкой «элемент занят пользователем …».
- **После «Применить» — синхронизация с освобождением элементов.** Плагин занимает все изменённые элементы.
- **Настройки окон хранятся в модели.** Кто последний нажал «Сохранить», тот и задал настройку проекта:
  в шапке окна видно «Настройка проекта: сохранил …». Договоритесь, кто в проекте отвечает за настройку.
- Работать двумя людьми одной и той же кнопкой одновременно пока не проверяли. Лучше по очереди.

## 7. Известные ограничения

| Что | Что делать |
|---|---|
| **Revit зависает при объединении** некоторых систем (на КрМа3 — «К1», «К4.1»). Зависает сам Revit, без плагина повторяется так же | Плагин запоминает копию, на которой Revit завис, и в следующий раз отмечает её «Не объединять». Если зависло: подождите 10 минут, затем закройте Revit через диспетчер задач и пришлите лог (раздел 8). Такая копия останется копией; в спецификации она всё равно попадёт в «К1», если спецификация группирует по LSR_Имя системы |
| **Отметка «Не объединять» — только на вашем компьютере** | Коллеги её не видят. Если копию не надо объединять никогда — скажите об этом тому, кто будет объединять |
| **Надстройка Citrus [BIM] «MEPUpdater»** мешала записи на КрМа3 | Если она сломала запись, плагин отключает её до перезапуска Revit и пишет об этом в отчёте. После перезапуска Revit она снова работает |
| **Имена труб — только проверка**, пока работает BIM2B | Не включать запись (5.10) |
| **Наименование изоляции и BIM2B** | Включили запись имени в «Изоляции» — уберите формулу имени изоляции в BIM2B, иначе имя перепишется |
| **«Кол.» в спецификации, исправленное руками**, перепишется расчётом | Используйте «SYS_Кол-во вручную» (5.8) |
| **Шнур не считается без связей АР/КР** при галке «Только гильзы в наружных стенах» | Загрузите связи и нажмите «Обновить» |
| **Трубы Rain Flow 60 и 100** имеют одинаковый комментарий к типоразмеру | Строки с одинаковым диаметром сольются в спецификации. Если это мешает — разные комментарии у типов |
| **Комплекты:** свой состав для одного типоразмера и импорт комплектов в другую модель ещё не проверялись на живом проекте | Проверьте результат в спецификации и сообщите, если что-то не так |

## 8. Если что-то пошло не так

| Ситуация | Что сделать |
|---|---|
| Нет вкладки VK Tools | Перезапустите Revit, на вопрос о надстройке — «Всегда загружать» |
| Кнопка серая | Открыто семейство, а не проект |
| «Применить» не нажимается | Сначала «Пробный прогон». Если после него поменяли настройку — снова «Обновить» и «Пробный прогон». Если есть красная строка «Запись запрещена» — прочитайте причину |
| Записалось не то | **Ctrl+Z** один раз — отменится вся операция VK Tools целиком |
| После «Применить» повторный анализ показывает изменения | Кто-то переписывает значения (BIM2B, формула). Сохраните CSV, пришлите |
| Операция идёт очень долго, «Отменить» не помогает | Скриншот окна прогресса, затем закрыть Revit. Прислать лог за этот день и журнал Revit |

**Где лог.** VK Tools → О программе → **Открыть папку логов** (`%LocalAppData%\VKTools\logs`).
Файл за день: `vktools-ГГГГММДД.log`.

**Где журнал Revit.** `%LocalAppData%\Autodesk\Revit\Autodesk Revit <год>\Journals\` — последний `journal.*.txt`.

## 9. Обратная связь

Нам важно всё: ошибки, непонятные слова в окнах, лишние шаги, чего не хватает для выпуска.
Пишите Радмиру в любом удобном виде. Чтобы разобраться быстро, приложите:

1. **Скриншот окна** плагина (с жирной строкой итога и вкладкой, где проблема).
2. **CSV отчёта** («Сохранить CSV…»), если речь о конкретных элементах.
3. **Лог за день**, если была ошибка или зависание.
4. **Версию** из «О программе».
