# Зависимости

Правило: сторонний пакет берём только после проверки лицензии и с точной версией. Ни «latest», ни
плавающих диапазонов. Лицензии ниже проверены по nuspec и файлам лицензий пакетов (2026-10-08).

## В поставке (едет к пользователю)

Сторонних DLL нет. Только собственные `VKTools.dll`, `VKTools.Core.dll`, CSV-правила и манифест.

## Отклонено

| Что | Почему |
|---|---|
| WiX 6 и новее | Open Source Maintenance Fee: для коммерческого использования WiX 6+ требует платного участия по EULA. WiX 5.0.2 — MS-RL без доплат |
| Inno Setup | лицензия «ожидает» покупку коммерческой лицензии при коммерческом и внутрикорпоративном использовании |
| Сторонние наборы иконок | значки рисуются в коде, лицензии не нужны |
| Сторонние CSV/JSON-библиотеки | парсер CSV свой (≈200 строк, покрыт тестами): в процессе Revit чужие версии Newtonsoft.Json и др. конфликтуют |
