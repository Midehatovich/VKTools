# Тестирование

## 1. Автотесты (CI, каждый PR)

`tests/VKTools.Core.Tests`, xUnit, всё, что не требует Revit:

| Область | Что проверяется |
|---|---|
| Чтение файлов | UTF-8 с BOM и без, UTF-16, Windows-1251 (CSV из Excel в ANSI), запись UTF-8 с BOM |
| CSV | комментарии, `#schema=N`, кавычки, переносы строк в поле, пустые строки |
| Загрузка правил | встроенные; папка отдела перекрывает; недоступная папка и битый файл → встроенные + запрет записи; новая/старая схема; нет колонки |
| Разбор правил | параметры (GUID, да/нет, привязка), повтор GUID, апдейтеры, ссылки на параметры |
| Встроенные правила | все файлы из `config/` загружаются без замечаний и сохранены в UTF-8 с BOM |
| Двойники значений | «B1»/«В1», регистр, пробелы, смешанные алфавиты, видимое представление для отчёта |
| Имена систем | все случаи `test_PipingSystemMerge_names.py` (v1.2): разбор номера, зоны В1.1/В1.2, К1/К1н, другой тип, почти совпадения, выбор копии; пакетные группы, копии без основной, основная в двух экземплярах |
| Отчёт | CSV: экранирование «;» и кавычек, защита от формул Excel (`=`, `+`, `-`, `@`) |
| Настройки и лог | чтение/запись, битый файл → умолчания, ротация логов |

Плюс сборка надстройки под все шесть лет Revit (2021–2026) с предупреждениями как ошибками и сборка MSI на Windows.

## 2. Проверка в Revit (каждый релиз, вручную)

Revit в CI нет, поэтому поведение в модели проверяется вручную по чек-листу на копии модели.
Начиная с Р1 к нему добавятся эталонные случаи из [discovery/GOLDEN-CASES.md](discovery/GOLDEN-CASES.md):
тот же результат, что у Dynamo-скрипта на той же модели.

системы, Q-201) проверяется шагом 4: если пробный прогон пишет «Revit сам назначил терминалам новую систему»,
механизм на этой сборке Revit не проходит — пришлите отчёт.

### Известные проверки, которые надо сверить на рабочей модели

- Списки категорий в `parameters.csv` предварительные (Q-024). Если «не назначен категориям» срабатывает
  там, где спецификации в порядке, — правим CSV, не код.

## 3. Регрессия

Каждая найденная в Revit ошибка → тест в Core (если воспроизводится без Revit) или строка в чек-листе выше.
