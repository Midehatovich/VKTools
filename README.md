# VK Tools

Надстройка Revit для отдела ВК: проверка модели перед выпуском и (в следующих релизах) автоматизация,
которая сейчас живёт в Dynamo-скриптах. Цель — рабочая документация по ГОСТ без ручной правки спецификаций.

Каждая изменяющая команда сначала показывает, что изменится, и пишет в модель только после «Применить».
Правила (нормы, таблицы, форматы) лежат в CSV вне кода: отдел правит их без программиста.

## Состояние

**Р1 — объединение систем** (этот релиз) поверх Р0. Вкладка «VK Tools» в Revit 2021, 2022, 2024:

| Кнопка | Что делает |
|---|---|
| Проверить модель | Только чтение. Параметры ФОП и их категории, апдейтеры других надстроек (BIM2B), пустые ADSK_Наименование, изоляция с другими этажом/системой, чем у основы, разные написания одного значения («B1» латиницей и «В1»). Отчёт с фильтрами, «Показать в модели», экспорт в CSV |
| Объединить системы | Копии систем трубопроводов «В1 1», «В1.2 3» → основные «В1», «В1.2». Окно «было → станет» по всем группам, пробный прогон с откатом, запись одной операцией отмены |
| Настройки | Папка правил отдела, срок хранения логов |
| О программе | Версии, папки логов и правил |

Дальше по плану ([SUMMARY](docs/discovery/SUMMARY.md#4-порядок-релизов)):

```
Р1  MEP   объединение систем «В1 1», «В1 2» → «В1»   ← готово
Р2  NEST + GRP   вложенные семейства, группирование, комплекты ШПК
Р3  CALC  окраска, крепления (кг), бентонитовый шнур, запас на хомуты
Р4  INS + SYS    изоляция, система и этаж
Р5  PIPE  проверка наименований труб
```

## Принципы

- Надёжность важнее автоматизации: нет данных или правила — значение не меняется, строка в отчёте. Данные не придумываются.
- Параметры ищутся по GUID из ФОП, не по имени.
- Никакого автозапуска (IUpdater): только по кнопке.
- Сторонние библиотеки — только с проверенной лицензией и зафиксированной версией ([DEPENDENCIES](docs/DEPENDENCIES.md)).
